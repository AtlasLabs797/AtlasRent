Clickable action; one primary per view region, secondary for the rest, danger for anulaciones, ai for agent actions.
```jsx
<Button icon="plus">Nueva factura</Button>
<Button variant="secondary" icon="download">Exportar</Button>
<Button variant="ai" icon="sparkles">Revisar con IA</Button>
```
Variants: primary · secondary · ghost · danger · ai. Sizes sm 32 / md 44 / lg 52 — always pills. In one action row keep every button the same size.
